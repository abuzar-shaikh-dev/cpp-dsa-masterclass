# C++ & Data Structures & Algorithms Masterclass

Welcome to the **C++ & DSA Masterclass** repository! This repository contains a structured, end-to-end roadmap taking you from absolute C++ syntax fundamentals ("Hello World") up to advanced algorithmic paradigms and data structures used in top-tier tech software engineering interviews.

---

## 📌 Repository Organization

This repository uses a **unified module structure**. Each module folder contains both **handwritten scanned PDF notes** (`notes-[folder-name].pdf`) and clean, well-commented **C++ source code files**.

## 🛠️ How to Compile and Run

To run any C++ code snippet locally:

```bash
# Compile using G++ with modern C++17 standard
g++ -std=c++17 -Wall 01_data_types_sizes.cpp -o output

# Run the compiled binary
./output
```
